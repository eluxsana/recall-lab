02 / DID IT LEARN?

From guessing to retrieving.

The line is development accuracy during a fixed training schedule. The final four-pair test uses a separate hash partition, with zero exact input overlap with training.

A perfect score on this finite synthetic task is a narrow result. It says nothing about natural-language ability, and it is not a claim about the entire input space.

Learned absolute positions are part of the experiment. New sequence lengths expose positions the model never trained on. The stress test changes both length and the number of pairs.

03 / WHERE DOES IT BREAK?

Longer context is a different test.

Training always used four pairs. Each stress setting uses 512 generated test examples. Displayed results use seed 42. The three-seed check reached 100% on the four-pair test; six-pair accuracy ranged from 72.3% to 77.7%.

Zero an attention head and measure the change

Each row zeros a head's value-weighted output before the output projection. “All” zeros all four head outputs in one layer. Accuracy can stay flat while cross-entropy rises. This tests one intervention, not a unique causal explanation.
